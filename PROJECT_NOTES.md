## Принятые решения и причины
- Основной тест: iPhone 17 Pro Max, iOS 26.1; разработка/проверка также на Windows. Установка Windows-программ отложена по решению владельца.
- Регистрация проекта: Россия, целевая аудитория Россия + мир. Пока разрешены только искусственные данные без реальных пользователей: вопрос локализации и других требований РФ не решён.
- Домен отложен; SMTP по этой причине не настроен. Денег и ключей сервисов сейчас не нужно.
- Сфера принята как концепт, подключение к реальным чатам — этап 7. В текущем приложении её нет, старая демоверсия сохранена в `prototype`.
- В `docs/SPEC.md` план предусматривает полную схему в этапе 1 и ссылки на этапе 4. **С согласия владельца от 28.10.2026** схема этапа 1 сокращена до таблиц, нужных для 1:1, а публичные ссылки перенесены внутрь ускоренного маршрута этапов 0–3. Исходный SPEC не меняем. Ссылки не открывают содержимое приватных переписок третьим лицам.
- На этапе 0 **нет ложных сообщений, фиктивной доставки и подключения серверов**; кнопка «Написать» отключена.
- Первая цветовая палитра в рабочей основе бирюзовая `#4DD0C7` **временно**, окончательный выбор акцента пока не подтверждён. Янтарный вариант оставлен в принятом концепте.
- Выбран Tailwind v3, чтобы хранить палитру и отступы в `tailwind.config.ts`, как прямо требует SPEC. На v4 переходить не нужно без согласования.
- Минимальный Service Worker сделан без дополнительных библиотек. Он кэширует только офлайн-страницу и иконку, не сообщения, не API и не авторизованные HTML-ответы. При будущем подключении Auth политика SW будет повторно проверена. Выбор полноценного SW-решения (Serwist/Workbox) отложен до согласования новой библиотеки.
- UI использует встроенные словари, а не i18n-библиотеку из SPEC. **Открытое расхождение до установки дополнительной библиотеки**, требуется отдельное разрешение.
- В CI вместо ESLint действует локальный проверяющий скрипт с небольшим набором правил; **это не полноценный линтер**, добавить ESLint после разрешения владельца. CI использует `npm install`, пока не создан lockfile, затем заменить на `npm ci`.
